# Экономический Discord-бот

Работает только в канале #корзина (ID задаётся в config.py).

Команды:
- Экономика: /daily /balance /pay /history (все операции, со страницами) /top
- Магазин: /shop /role_create /inventory
- Любовные комнаты: /marry /love_profile /divorce.
  Кнопки «Продлить» и «Скинуться в копилку» — в своём /profile и в /love_profile.
  Продлить может любой из пары: сначала тратится копилка, остальное — с баланса нажавшего.
  Если в копилке хватает денег, комната продлевается сама (настройка в /panel).
  При расставании остаток копилки возвращается каждому его часть.
  Канал комнаты создаётся при входе в голосовой «Войти» (ID в config.py)
- Игры: /duel (соперник необязателен) /coinflip /slots /roulette /log
- Профиль: /profile
- Админ (роль из config.py): /panel — настройки, напоминания, управление комнатой участника

Напоминания: за N часов (по умолчанию 48) до конца срока роли или комнаты бот пишет в ЛС.
Если ЛС закрыты — упоминает участника в #корзина. Настраивается в /panel → «Напоминания».

Запуск:
1. pip install -r requirements.txt
2. Скопируй .env.example в .env и заполни DISCORD_TOKEN и GUILD_ID
3. В Developer Portal -> Bot включи «Server Members Intent»
4. python bot.py

Сообщения бота видны всем и удаляются через 20 секунд (config.MESSAGE_LIFETIME).
Не удаляются только /profile и /balance. Панель /panel остаётся скрытой (видна только админу).
Боту нужны права: Управление каналами, Перемещение участников, Управление ролями.
